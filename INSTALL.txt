ELC — полный архив проекта с backend-лицензированием

В архиве находится весь исходный проект:
- client/ — сайт React + TypeScript + Vite;
- server/ — backend Node.js + Express + TypeScript + SQLite;
- package.json и lock-файлы;
- ELC-LICENSE-API.md — контракт интеграции macOS-приложения;
- README.md — установка, запуск и описание текущей схемы.

Изменения лицензирования:
- POST /api/activation/challenge;
- POST /api/activate — активация с подписью ECDSA P-256;
- POST /api/activation/check — проверка лицензии;
- старый небезопасный маршрут с доверенным deviceId удалён;
- повторная активация с тем же публичным ключом разрешена;
- другой ключ получает device_mismatch;
- поддержка может сбросить привязку, запись о сбросе сохраняется;
- миграция добавляет недостающие столбцы и таблицу challenge.

КАК ПРИМЕНИТЬ
1. Сначала сделайте копию текущей папки проекта.
2. Распакуйте архив в новую папку либо поверх исходников проекта.
3. НЕ удаляйте и не заменяйте существующие server/.env и server/data/ (если они есть).
4. Установите зависимости: npm run install:all
5. Выполните сборку из корня: npm run build
6. Перед запуском создайте server/.env по инструкции в README.md. Если свой .env уже есть — сохраните его и не отправляйте никому.
7. Не выкладывайте backend на Railway до резервного копирования production SQLite и интеграционных тестов со Swift-приложением.

ЧЕГО НЕТ В АРХИВЕ И ПОЧЕМУ
- .env и резервные копии env — могут содержать секреты;
- server/data/ и SQLite — пользовательские данные;
- node_modules/ — устанавливается через npm;
- .git/ — локальная история репозитория;
- dist/ — генерируется командой сборки.

ВАЖНО
- PAYMENT_PROVIDER=mock — тестовая имитация оплаты, не реальное списание денег.
- В архиве есть только backend-часть лицензирования. Swift-приложение ещё должно реализовать CryptoKit, Keychain, запросы API и блокировку функций до успешной проверки лицензии.
- ADMIN_TOKEN нельзя встраивать в приложение, сайт или передавать товарищу.
- Старые привязки через deviceId не мигрируют автоматически. Для переноса требуется ручной сброс поддержкой.
